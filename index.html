Terminal for Agentic Coding

A tiny desktop IDE built for one job: supervising AI coding agents. Run claude, codex, gemini — any terminal agent — each in its own folder, side by side.

Why Tigriden?

Agentic coding means running several agents in several folders and checking in on them. A full IDE is overkill for that; a bare terminal multiplexer gives you no file browser and no editor. Tigriden is the minimal middle: one window, one session per folder, agent + files + editor together.

Not a full IDE

No run/debug tooling, no LSP

The agents do the heavy lifting. Tigriden skips the machinery you don't need when an agent is writing the code.

Not a bare multiplexer

Files and editor included

tmux gives you terminals but no file browser and no editor. Tigriden pairs every terminal with a live tree and a real editor.

The minimal middle

Eyes and hands on your agents

Watch the file tree update as agents work, inspect what they produce, and tweak files without leaving the window.

Features

Everything you need to steer parallel agents — and nothing you don't. No webview, no Electron, no C regex libraries. Slint UI with both panes rasterized straight to pixel buffers.

🚀

One-click agents

Preset buttons type the agent command into the terminal for you — fully configurable via config.toml.

🗂️

Multiple terminals per folder

The + tab spawns extra shells in the same workspace, so one agent runs while you use another terminal for git, tests, or a second agent.

💻

Real terminal

VTE-compliant emulation (alacritty_terminal + a real PTY). vim, top, and the Claude Code TUI just work — bracketed paste, truecolor, mouse selection, image paste into Claude Code.

🌲

Live file tree

Gitignore-aware, refreshes automatically as agents create and delete files. Right-click for New File/Folder, Reveal in Finder, Duplicate, Rename, Move to Trash and more.

📎

Drag & drop files

Drop any file from Finder onto the window and its shell-quoted path is typed into the terminal — attach files to an agent prompt like in a native terminal.

✏️

Built-in editor

Syntax highlighting for 40+ languages (cosmic-text + syntect), edit and ⌘S save. When an agent edits the open file on disk, it reloads automatically.

👁️

File viewers

Images, Markdown rendered with headings and inline pictures, CSV/TSV as aligned tables, PDF text extraction. Toggle between rendered view and editable source.

📁

Per-folder sessions

Each workspace keeps its own shell, tree, and open file; switching is instant.

🕐

Recent folders

Every folder you add is remembered permanently. Reopen from the ⟳ button or File ▸ Open Recent — even after removing it from the workbench.

💾

Persistent

Folders, active session, and layout are restored on relaunch. Fresh shells each time by design.

🍎

Native macOS

Real menu bar (File, Edit) routed to whichever pane has focus. Dock icon, drag-to-Applications app bundle.

Install

Prebuilt binaries are available — no Rust required. macOS is the primary target; Linux/Windows are untested but the stack is cross-platform.

Quick install (macOS)

⬇ Universal App Bundle Apple Silicon + Intel · Drag to /Applications ⬇ Binary · arm64 Apple Silicon bare binary ⬇ Binary · x86_64 Intel bare binary

First launch only: the app isn't notarized — right-click → Open → Open, or run:
xattr -d com.apple.quarantine /Applications/Tigriden.app

Build from source

zsh
$ git clone https://github.com/Sompote/Tigriden.git
$ cd Tigriden
$ cargo build --release
$ ./target/release/tigriden

Stable Rust required. Or run ./bundle/make-app.sh for dist/Tigriden.app.

Usage

Click + Add folder and pick a project directory — a login shell opens there.

Click a preset button (e.g. claude) to launch the agent, or type any command.

Watch the file tree update as the agent works; click any file to inspect or tweak it.

Click + in the terminal tab strip to open more terminals in the same folder — each tab is its own shell.

Add more folders to run more agents in parallel; switch by clicking a session in the sidebar.

Click ⟳ (bottom of the sidebar) to reopen any previously added folder without the file dialog.

Configuration

theme = "dark"          # "dark" | "light"
font_family = "Menlo"
font_size = 13.0
scrollback = 10000

[[presets]]
label = "claude"
command = "claude"
send_enter = true

[[presets]]

Architecture

Slint provides only the chrome (sidebar, layout, splitter). The two hard parts are custom-rendered pixel panes on the CPU:

PaneEngineRendering
Terminalheadless alacritty_terminal grid fed by portable-ptyglyphs rasterized per cell via cosmic-text's swash cache
Editorcosmic-text SyntaxEditor (syntect highlighting)draws itself into the same pixel-buffer canvas

vendor/cosmic-text/ is a verbatim copy of cosmic-text 0.19 with one change: its syntect dependency uses the pure-Rust fancy-regex engine instead of oniguruma (no C build dependency, smaller binary).
